# HSHS Campus System (海山高中校園整合系統)

本專案為部署於 PythonAnywhere 的單一 Flask 應用，整合了 LINE 機器人、學生服務網站，以及校慶紀念服預購平台。

## 系統總覽

1. **CampusBot (LINE 機器人)**
   處理高頻率的即時查詢。包含：查詢當日菜色與週三行程、串接 API 提供天氣與新聞、非關鍵字訊息自動存入後台待處理。
   ![CampusBot功能](CampusBot.png)
3. **CampusHub (學生服務網站)**
   處理複雜查詢與長篇回饋。包含：填寫意見回饋表單、搜尋教師辦公室與班級課表，以及提供圖形化後台供幹部更新處理進度。
   ![CampusHub功能](CampusHub.png)
5. **校慶紀念服訂購平台**
   提供購物車與訂單修改功能，預購結束後產出對應收費與發放流程的 Excel 報表。（註：此功能由個人設計流程與規則，程式碼由 AI 輔助生成）

## 檔案結構導覽

主要結構如下：

* `flask_app.py`：後端主程式，包含所有路由設定、資料庫模型與業務邏輯。
* `templates/`：前端 HTML 模板資料夾[cite: 55]，內部依功能分類：
  * `student/`：學生服務中心（含查詢功能與表單入口）[cite: 55]
  * `menu_comment/`：營養午餐意見等相關表單[cite: 55]
  * `order/`：校慶紀念服訂購與購物車頁面[cite: 55]
  * `manager/`：圖形化後台與管理端頁面[cite: 55]
